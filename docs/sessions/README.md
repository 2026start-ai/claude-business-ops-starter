Daily session logs land here as `<YYYY-MM-DD>.md`, written automatically
by `.claude/hooks/post-commit-log.sh` (linked worktrees get
`<YYYY-MM-DD>_<branch>.md`). Don't create files here by hand — Claude
appends inline notes to today's file as work happens, and a `## Next
move` section at close-out marks the resume point for the next session.
