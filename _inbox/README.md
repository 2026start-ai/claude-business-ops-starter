Drop zone. Put screenshots, CSVs, photos — anything you want the next
Claude session to see — in here. The session-start hook announces
whatever's waiting, so "I dropped it in _inbox" Just Works with no path
pasting.

Contents are gitignored (transient hand-off, not source). Once a file
has been used, move it to its permanent home or delete it — a stale
_inbox nags every session.
